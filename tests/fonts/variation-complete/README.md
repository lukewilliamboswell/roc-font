These fixtures exercise variable-font behavior through the public served bundle. Run `ROC=/path/to/latest/roc python3 tests/fonts/variation-complete/verify.py`. The optimized native query replays 139 actual cached HarfBuzz 14.6.0 cases and repeats the complete request stream to check determinism. `tests/api/VariationCompletionTests.roc` adds public malformed-table and absence contracts.

The original fonts are generated by `generate.py` with fontTools 4.61.1 and licensed under `SYNTHETIC-LICENSE.txt` (UPL 1.0). Three increasing contour sizes (4, 64, 512) distinguish sparse phantom queries from whole-contour evaluation; three increasing axis sizes (8, 32, 128) pin normalization scaling. avar2 stores with 8, 32 and 128 active regions measure cross-axis delta evaluation independently. The 16382-axis positive fixture exercises the largest axis count whose required fvar instanceSize fits U16. The 16383-axis malformed fixture has unrepresentable instanceSize; OTS 9.3 accepts the container after explicitly dropping fvar. `ots.json` records retained and discarded tables, not just the process exit code.

The cached facts come from uharfbuzz 0.56.3/HB 14.6.0, with independent FreeType 2.13.2 unhinted/unscaled metrics for ordinary simple and real fonts. fontTools 4.61.1 records the independent avar2 remapping. All actual oracle versions and font hashes are cached with the cases. A fontTools discrepancy is recorded rather than overwritten: its mathematical avar2 result can differ from pinned HB binary32 rounding and scalar-cache semantics. The controlled tiny-region case returns raw 2.14 coordinates [2,1,1024] in HB and [17,17,1024] in fontTools. Roc deliberately matches HB's first-use scalar behavior for avar2; shared MATH/color precise scalar APIs remain unchanged.

Primary behavior references:

- HB 14.6.0 `hb-font.cc`, `hb_font_set_variations`: every matching axis tag is assigned; later caller settings win. `hb_ot_var_find_axis_info` instead finds the first matching axis. The public font setter follows the former. No font axis is renamed, reordered or dropped. [Source](https://github.com/harfbuzz/harfbuzz/blob/14.6.0/src/hb-font.cc).
- HB 14.6.0 `OT/Var/avar/avar.hh`, `map_coords_16_16`: cross-axis deltas all use the complete pre-delta coordinate vector, then clamp the final coordinates to the format's normalized range. Nullable/empty maps use implicit axis row indices; no-variation sentinels and nullable stores produce zero delta. [Source](https://github.com/harfbuzz/harfbuzz/blob/14.6.0/src/OT/Var/avar/avar.hh), [avar2 proposal](https://github.com/harfbuzz/boring-expansion-spec/issues/14).
- HB 14.6.0 `OT/glyf/Glyph.hh` copies USE_MY_METRICS phantom points before applying component transforms; the last flagged component wins, including nested components. At zero normalized coordinates `hb-ot-font.cc` bypasses gvar metric evaluation and reads the parent hmtx. HVAR takes priority when present. [Glyph source](https://github.com/harfbuzz/harfbuzz/blob/14.6.0/src/OT/glyf/Glyph.hh), [font source](https://github.com/harfbuzz/harfbuzz/blob/14.6.0/src/hb-ot-font.cc).
- HB 14.6.0 `OT/glyf/glyf.hh` caps the rounded nonnegative phantom span at binary32 2^31. Horizontal hb_position_t then converts that boundary to MIN. The public vertical distance widens to I64 to preserve its truthful positive magnitude; shaped vertical advances match HB's signed conversion. The five boundary fonts establish both signs of origin clipping, negation of MIN and spans above 2^31. [Source](https://github.com/harfbuzz/harfbuzz/blob/14.6.0/src/OT/glyf/glyf.hh).

Reading validates every avar2 explicit and implicit delta reference, including unused map entries, before queries. Invalid optional avar is dropped and reported in lenient mode; strict mode rejects it. This is deliberately stricter than HB's guarded zero-delta access to invalid indices and follows the package's validated-font contract. Named instances containing distinct values on repeated axis tags remain a caller limitation: tag-based setting cannot independently select those axis positions; no positional public selector is introduced here.
