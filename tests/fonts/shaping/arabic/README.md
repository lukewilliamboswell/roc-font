# Arabic shaping reference fonts

Two unmodified, freely licensed font families exercise joining, contextual
substitutions, ligatures and positioning independently of tiny synthetic
fixtures: Noto Sans Arabic 2.013 and Noto Naskh Arabic 2.021.

`sources.json` pins the upstream release archive, the extracted Regular
TrueType member, and each licence by SHA-256. The matching OFL 1.1 texts
are included beside the fonts. Only tests and fuzz targets import these
files; they are never part of the package bundle.
