# David Libre Regular

This static TrueType fixture is the unmodified David Libre Regular 1.100
from the David Libre upstream commit
[15496c1be77e35f3fa3d0df14a2c2c6f9adfd297](https://github.com/meirsadan/david-libre/tree/15496c1be77e35f3fa3d0df14a2c2c6f9adfd297/fonts/ttf).
Its SHA-256 is `923f06e0f6dc84e1649d8cc5d5e12a8d663adf6aba83ba15baa5d559fb47b86e`.

The font is licensed under the [SIL Open Font License](OFL.txt). It
exercises the Hebrew language system through the `hebr` script,
with vowel placement from `mark` and a combining-accent stack from
`mkmk` in the same run.
