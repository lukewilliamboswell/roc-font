## Fonts in the package source

Three unmodified upstream fonts live in `package/fonts/`, each beside its
complete licence. Every file is pinned by SHA-256 and size, with its upstream
release archive, in
[`tools/default-fonts/pins.json`](tools/default-fonts/pins.json);
`tools/default-fonts/verify.py` checks them.
[docs/default-fonts.adoc](docs/default-fonts.adoc) explains what the
licence allows and the rule that a shipped file is never modified.

| File | Family | Licence | Copyright | Reserved Font Name |
| --- | --- | --- | --- | --- |
| `package/fonts/Inter-Variable.ttf` | Inter 4.1 | SIL Open Font License 1.1, `package/fonts/Inter-OFL.txt` | Copyright (c) 2016 The Inter Project Authors | none |
| `package/fonts/Merriweather-Variable.ttf` | Merriweather 4.009 | SIL Open Font License 1.1, `package/fonts/Merriweather-OFL.txt` | Copyright 2020 The Merriweather Project Authors | "Merriweather" |
| `package/fonts/FiraCode-Variable.ttf` | Fira Code 6.2 | SIL Open Font License 1.1, `package/fonts/FiraCode-OFL.txt` | Copyright (c) 2014, The Fira Code Project Authors | none |

The fonts' `name` tables carry these trademark notices: "Inter UI and Inter
is a trademark of rsms.", "Merriweather is a trademark of Sorkin Type Co."
and "Fira Mono is a trademark of The Mozilla Corporation."

`Font.sans`, `Font.serif` and `Font.mono` read these files, and the
package bundle carries each font with its licence text, unmodified
(`Font.sans_licence` and its siblings expose the texts).

## Embedded shaping data and algorithms

Unicode character and joining properties in `package/ShaperUnicodeData.roc`,
`package/ShaperJoiningData.roc` and the Unicode-derived Indic shaping
properties in `package/ShaperIndicData.roc` come from Unicode 18.0.0 files pinned
in `tools/ucd/pins.json`, `tools/ucd/joining-pins.json` and
`tools/ucd/complex-pins.json`. The data is under
Unicode License V3. Its complete notice is in
[`tools/ucd/UNICODE-LICENSE.txt`](tools/ucd/UNICODE-LICENSE.txt) and is
preserved by the generators in the bundled data modules.

The script shapers (`ShaperArabic`, `ShaperThai`, `ShaperHangul`,
`ShaperIndic` and its syllable machine) and generated state-machine tables
are adapted from HarfBuzz 14.6.0. Each adapted module carries HarfBuzz's
complete Old MIT copyright and permission notice. Original pinned upstream
generators and state machines are under `tools/ucd/complex-src/`, beside
their `COPYING` notice. These data and algorithm notices reach the package as source comments; the test fonts
listed above do not.

## Downloaded on demand, never committed

`scripts/fetch_corpus.py` downloads the fonts pinned in `tests/corpus.json`
(Inter, Source Sans, Noto, the HarfBuzz test suites and others) into the
git-ignored `tests/corpus/`, each beside its upstream licence file
(`LICENCE-*`). Tests imported from them into the git-ignored
`tests/cases/harfbuzz/` keep their suite's licence.
